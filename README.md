# Awinjas Boutique

A responsive, static boutique storefront for Awinjas Boutique in Kitengela. Product prices are shown in Kenyan shillings (KSh); shoppers can filter the collection, build a saved shopping bag, and send an order through WhatsApp.

## Run locally

Open `index.html` in a browser. No build step, package installation, or server is required.

## Store details

- Location: KIGNDOM BUSSINESS CENTER, Kitengela
- Phone: 0702256455
- Currency: KSh

Product and fashion photography is loaded from Unsplash. The bag is stored in the visitor's browser; WhatsApp is used to confirm stock, sizing, and delivery.
